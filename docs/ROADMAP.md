# 个人 AI 成果工作台：实施路线

## 已确认的产品边界

- 以「成果工作台」为主线，以「AI 委托与验收」为 DSH 专属入口。
- 面向个人，优先高效、快捷、低维护成本；暂不涉及团队权限、协作、账号和云同步。
- AI 是表达、整理与分析的底座；不为每次渲染调用模型。
- 自动收集执行回执不等于接受交付；问题提示不等于事实判定；报告自动生成不等于自动发布。
- 不增加 doing 状态、看板、甘特图或复杂任务树。
- 各阶段独立提交与验证；打 tag、推送和发布按用户要求另行执行。

## M0 / 1.3.2：可信底座

### F01 保存失败可见
- 普通写失败保留当前内存修改、持续警告、重试保存与导出。
- 损坏的本地数据不能被当作空库自动覆盖。
- 检测到其他窗口修改后暂停本页写入；不声称已实现多窗口并发事务。

### F02 报告草稿保护
- 周期、报告类型、项目共同确定报告身份。
- 未保存编辑按身份保留本地缓冲，切范围和刷新不静默丢失。
- 无关批量生成不能重置当前编辑；同数量恢复也必须刷新编辑器。
- 在途生成/润色不得覆盖新编辑；工作空间恢复后旧请求失效。
- 源任务删除后，再保存报告仍保留原依据快照。

### F03 可靠回传
- Host 使用宿主 KV backend 保存队列，持久化成功后才返回成功。
- 容量满拒绝新回传，禁止静默淘汰旧条目。
- 可选 requestId 支持有限保留期内的幂等重试；同键不同内容拒绝。
- 业务采纳时，任务记录、成果与已处理标记一起提交；服务端确认失败可重试。
- 回传接口不是客户端业务采纳接口；不允许工具替用户验收结果。

### F04 安全导入与恢复
- 覆盖需要完整备份；合法空备份可以往返；非法记录和超范围输入整体拒绝，不截断。
- 导入/清空/恢复前，安全快照失败即停止操作。
- 多分区提交使用回退日志；中断后先恢复，再加载工作空间。
- 恢复使旧撤销、预览与在途 AI 请求失效。
- 每日快照仍与原数据同存储；外部 JSON 文件才是独立副本。

验收：配额错误、每个分区写失败、回退失败后重挂载、重复回传、Host 重建、异步响应过期、项目切换、空库撤销均需测试。VM 测试不能替代真实桌面应用验收。

## M1 / 1.4.0：快捷记录与执行入口

### D01 个人本地数据主存
- 使用已核验的 Host 持久层保存任务、项目、记录、成果和报告。
- localStorage 作为迁移来源与缓存；迁移备份、完整性校验、可回退。
- UI 与工具共用业务操作；写入含修订/冲突反馈，拒绝陈旧整库覆盖。
- 后台能在面板未打开时读取工作数据，为自动化提供前提。

### R01 AI 快捷记录
- 一句话识别待办、进展、成果、下一步，并关联已有任务。
- 信息明确时不反复追问；有歧义时只问必要问题。
- 自动整理与业务修改分权；完成、延期、删除仍需用户明确授权。
- 简单记录的体验目标是约 10 秒内完成，作为测试目标而非未经实测的承诺。

### R02 当前上下文
- 当前任务/项目/报告成为明确上下文，用户不用重复名称。
- 只加载必要摘要；敏感数据外发范围与使用模型可见。

### R03 会话与成果关联
- 已接入：工具回传由宿主附加实际来源会话；AI 快捷记录和整理保留原文与摘要。
- 已接入：成果支持实际本地文件的纯文本路径引用，可复制路径、通过宿主打开来源会话，不自动读取或执行文件。
- 边界：任意历史会话选段导入、文件原生预览尚未实现；不将引用误称为已验证的交付物。

### R04 最小派活
- 任务提供目标、背景、预期成果、验收标准，关联执行会话。
- 先做明确委托与结果回收，不默认无限自主执行。

验收：实际任务从一句话记录/委托到回传关联；不需要用户重复复制任务标识；低置信度关联不冒充确定匹配。

## M2 / 1.5.0：主动与自动

### A01 问题雷达
- 检测临近截止、长期阻塞、缺乏近期记录、待处理回执、完成后缺成果引用。
- 本地规则筛选，AI 按需解释：现象、依据、可选行动。
- 「无记录」不推断为「未工作」；重复提醒合并，支持稍后提醒和忽略。

### A02 自动工作报告
- 用户开启后生成每日摘要、周报、月报草稿；默认不启用任何实际计划任务。
- 依据不足明确标注，无新依据不机械生成；每个关键结论可追溯。
- 自动稿与手工修改分离，禁止覆盖用户编辑；同周期幂等、失败可重试。
- 应用未运行时不能承诺按时执行；启动后的补生成规则明确。

### A03 自动化控制
- 显示开关、时间/时区、数据范围、模型、预算、最近结果、暂停与重试。
- 确认策略后再创建用户的实际调度，不把规划等同于调度授权。

## M3 / 1.6.0：验收与复用

- V01：结构化回执——做了什么、产出位置、验证方法、剩余问题。
- V02：接受结果/要求补充/继续推进；回传成功不是任务完成。
- V03：任务、记录、成果、报告统一全文检索，先不引入向量数据库。
- V04：用户主动设置报告格式、详略与风格，避免未经同意的隐式学习。
- V05：按当前任务推荐相关历史成果，帮助减少重复劳动。

## 产品验收指标

记录耗时、额外维护时间、提醒促成行动的比例、可交付报告准备时间、结果找回与复用率。任务数量、AI 调用量和报告生成数量不作为主要成功指标。
