# 工作面板 · Work panel

DeepSeek Harness（DSH）的个人任务与成果工作台：记录待办、整理工作进展、让 AI 协助执行，再把成果汇总成周报或月报。

适合个人使用，无需额外账号，不提供团队协作或跨设备云同步。

## 安装

### 安装前准备

- 已安装并能正常使用 DeepSeek Harness，使用支持插件的 Web 界面或桌面应用。
- 如需 AI 建议、工作助手和报告生成，请先在 DSH 中配置可用的模型服务。
- 已有工作面板数据时，升级前先在 **设置 → 数据管理 → 导出备份** 保存一份 JSON 备份。

### 方式一：在 DSH 中安装（推荐）

在 DSH 对话中发送：

```text
请安装工作面板插件：github:qtsunami/lx2u-work-panel
```

按提示授权安装，并在插件管理中确认 **工作面板（@local/work-panel）** 已启用。安装结果若提示需要重启，请重启 DSH；否则刷新页面，再从 DSH 侧边栏打开 **工作面板**。

> GitHub 安装使用仓库中已提交的内容，不包含开发目录里尚未提交的修改。

### 方式二：从本地目录安装

先获取源码：

```bash
git clone https://github.com/qtsunami/lx2u-work-panel.git
```

在 DSH 的 **插件 → 添加插件** 中选择仓库目录，或在对话中发送：

```text
请安装这个本地插件目录：/绝对路径/lx2u-work-panel
```

选择包含包清单的仓库根目录，而不是其中的源码子目录。安装完成后确认插件已启用，并按安装结果提示刷新或重启。

普通安装不需要自行编译。修改源码后再安装的开发者，请参考[开发指南](<docs/DEVELOPMENT.md>)。

## 首次配置

不使用 AI 时，可以直接创建任务、编辑描述、记录进展和管理成果。

AI 功能需要插件使用的模型在当前 DSH 配置中可用。默认配置使用：

```yaml
provider: deepseek-account
model: deepseek-flash
```

如果你使用其他模型服务，可让 DSH 助手将工作面板的 `provider` 和 `model` 改为当前已配置的服务与模型。不要把 API Key 写进仓库。

**设置 → 自动报告** 中的模型选项只影响自动报告，不会替换其他 AI 功能使用的模型。

## 快速开始

1. 打开 **工作面板 → 全部任务**。
2. 输入任务标题，按 **Enter** 或点击 **添加任务**。日期可手动选择，也可输入“明天下午整理方案”等包含日期的文字；请检查识别出的截止日期。
3. 点击任务，在右侧填写描述、预期结果和下一步。
4. 工作推进后，在 **记录** 中保存进展，在 **成果** 中关联结果摘要或链接。
5. 需要 AI 帮忙时，使用任务底部的 **AI 建议 / 工作助手 / 交给 AI**。
6. 完成后手动勾选任务；需要总结时打开 **报告 → 周报/月报**。

## 日常使用

### 清单与任务

- 左侧 **清单** 旁的 `+` 用于新建清单，按工作领域或项目整理任务。
- 任务详情底部左侧的文件夹入口可切换所属项目；也可右键任务，通过 **移动到** 调整归属。部分界面仍使用“项目”称呼。
- **今天到期 / 已逾期** 帮你查看近期安排，**已完成/废弃** 汇总已结束的任务。
- 不再继续的任务可在详情 `⋯` 菜单中标记为废弃；误删任务可到 **回收站** 恢复，彻底删除需要确认。
- **统一检索** 可搜索任务、工作记录、成果和报告，不调用 AI。

### 任务详情

标题下方有四个标签页：

| 标签页 | 用途 |
| --- | --- |
| 描述 | 就地编辑任务说明，支持常用 Markdown |
| 执行 | 填写预期结果、下一步和阻塞问题 |
| 记录 | 追加进展、问题、决定等工作记录 |
| 成果 | 保存结果摘要、关联链接或文件引用 |

描述中输入 `# `、`## `、`### ` 可创建标题，`- ` 创建列表，`- [ ] ` 创建复选框。在行首或空格后输入 `/` 或 `、` 可打开样式菜单，也可从中选择 **关联任务**。

标题编辑时保留 `#` 标记，换行或离开后隐藏。列表与复选框输入标记及空格后即时成型。编辑按行进行，不等同于完整的 Markdown 文档编辑器。

### AI 协作与执行回传

- **AI 建议**：分析当前任务，建议需由你采纳后才会写入。
- **工作助手**：点击 **生成工作建议** 后，结合任务记录、相关成果和待确认回传整理下一步；写入前需要确认。
- **交给 AI**：准备执行指令，点击 **打开执行草稿** 后由你检查并发送，不会自动启动执行。
- **报告 → 执行回传**：查看 AI 提交的进展与成果，核对后采纳或验收；回传不会自动把任务标记为完成。
- **报告 → 需要注意**：查看本地规则发现的逾期、长期未记录等提醒，可稍后处理或忽略。提醒不等于 AI 对实际工作情况的判定。

可让执行任务的 DSH 助手使用 `work_panel_report` 回传结果；如果需要精确关联任务，优先从该任务的 **交给 AI** 入口准备指令。

> AI 功能会将相关任务内容、记录或成果依据发送给已配置的模型服务。使用前请检查是否包含敏感信息；模型建议和引用仍需人工核对。

### 周报与月报

1. 打开 **报告 → 周报/月报**，选择报告类型、周期和项目范围。
2. 检查右侧的本期依据，按需取消不希望纳入的任务。
3. 点击 **生成本期报告**，检查生成的正文及来源引用。
4. 按需编辑并保存草稿，或复制、导出 Markdown。

生成依赖已记录的工作依据。资料不足时，先补充任务记录和成果，不要把生成内容直接当成已验证事实。

## 设置与数据备份

点击左侧底部的 **设置齿轮**，在左侧选择分类，右侧修改对应内容：

| 分类 | 内容 |
| --- | --- |
| 报告表达偏好 | 报告排版、详略和语气，影响后续生成，不改写已有草稿 |
| 自动报告 | 启用开关、周期、时间、时区、模型和数据范围 |
| 数据管理 | 版本与占用、同步状态、备份、导入、恢复和清空 |

**自动报告默认关闭，仅在工作面板打开期间运行。** 关闭应用后不会按时生成；生成结果是草稿，不会自动发布。

工作数据主存保存在本机 DSH Host，浏览器保留缓存和待同步修改。建议定期在 **设置 → 数据管理** 中导出独立 JSON 备份。

- **合并导入**：按 ID 合并，冲突时保留更新时间较新的记录。
- **覆盖导入**：用备份替换当前工作数据，操作前会保存可撤销快照。
- **恢复**：可使用每日快照、撤销上次导入/清空；有迁移副本时也会显示相应恢复入口。
- **清空**：需要确认；操作前保存快照失败时不会继续。

应用内快照不等于外部备份。不要通过清除浏览器缓存来处理同步故障。

## 常见问题

**安装后找不到工作面板？**

先在插件管理中确认已启用；按安装提示重启 DSH，并刷新页面。版本可在面板左下角或 **设置 → 数据管理** 查看。

**AI 功能不可用？**

检查 DSH 模型服务和工作面板使用的模型配置。任务的手动创建、记录和数据管理不依赖 AI。

**提示离线、冲突或保存异常？**

先导出当前备份，再按提示重试同步。选择“备份后加载主存”会用主存内容替换当前页面，不会自动合并未同步修改；确认前请检查备份。
